# BEU Venture Website

A lightweight, human-designed static website for BEU Venture.

## Files
- index.html — main page
- styles.css — design and responsive layout
- script.js — mobile menu and footer year

## Publish
Upload all three files to any static hosting provider, keeping them in the same folder.

## Before launch
1. Replace any placeholder resource links (`#`) with real pages.
2. Add only verified/current opportunities.
3. Add a real privacy/contact page if collecting user data.
4. Submit the live domain and sitemap in Google Search Console.
5. Keep the independent-community disclaimer visible.
